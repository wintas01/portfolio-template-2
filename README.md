# Portfolio Template 2 — ECHO

A cinematic, scroll-driven portfolio in a single HTML file. No build step and no dependencies — just open `index.html`.

## Scenes
1. **Intro** — glowing "ECHO" logo with a self-drawing wobbly outline that blurs into the site
2. **Hero** — giant "EXPLORE MY PORTFOLIO" headline with a silhouette portrait
3. **About** — black-and-white starry-swirl sky; the "ABOUT ME" card splits open and expands into a light-beam scene with scrambling text
4. **Experience** — glowing scanline titles sliding sideways over giant ghost text
5. **Featured projects** — landing pages on a curved 3D ribbon that rotates as you scroll
6. **Services & Contact**

## Customise
All text is placeholder. The portrait, sky, light-beam figure and project previews are drawn in code — replace them with your own photo and screenshots for the best result.

## Deploy
Works on GitHub Pages: **Settings → Pages → Deploy from branch → `main` / root**.
